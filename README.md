## File Organization
* **`index.html`**: Serves as the structural container and user interface foundation for the web application.
* **`taskManager.js`**: Contains the core classes (`Task` and `TaskManager`) that handle state management, properties, and manipulation methods.
* **`api.js`**: Manages data fetching to retrieve the user's tasks.
* **`main.js`**: The executable script connecting the HTML structure with JavaScript logic.It handles loading tasks, delete/add tasks and button specification.
* **`styles.css`**: customizes completed tasks with line-through layouts for better visualization.
